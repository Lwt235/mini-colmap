# 3DGS 训练优化与消融实验

本文记录 2026-10-19 起的训练策略改进、对照设计、历史结果和复现步骤。原始 SfM 模型、照片和已有训练输出保持只读。公开指标见 [紧凑实验记录](../reports/README.md)，完整原始报告留在本地并由 Git 忽略。数学实现与 CUDA 库的职责见文末。

## 为什么修改

原训练器每到增密间隔，就把所有高斯重新包装成 Parameter，并创建全新的 Adam。即使拓扑未改变，已有高斯的一阶动量、二阶动量及步数也被丢弃。另一方面，位置、尺度、旋转、SH 和透明度共用一个学习率；密度控制只看一次三维中心梯度；损失只有 MSE。这些机制通过原有数学测试，实际画质由下述对照实验评价。

本次保留可显式选择的旧行为，在相同分辨率、地图和训练步数下测量改动收益。

## 修改清单与机制

### 1. 拓扑改变时迁移 Adam 状态

新增 `src/minicolmap/rendering/gaussian_training.py`，集中实现训练策略。原 `algorithms.densify_and_prune` 仅扩展可选参数 `return_lineage=True`；原调用仍返回同样的字典，新调用额外获得输出行对应的旧行索引及新增行标记，原有剪枝/子高斯公式不变。

例如旧高斯行 `[A,B,C]` 变为 `[C,A,A的子高斯]` 时，Adam 的 `exp_avg`、`exp_avg_sq` 同样重排为 `[C的状态,A的状态,0]`。保留行继续使用历史动量；新增行从零动量开始；删除行的状态移除；Adam 标量步数继续累积。透明度显式重置时，仅清零该参数的动量。

`gaussian.optimizer_state=preserve` 是新默认；`reset` 精确表示历史上每次整体重建优化器的控制组。改动后，旧配置会自动补上 `preserve`，旧 checkpoint 的渲染结果保持一致；如需重训复现旧训练行为，应显式填写 `reset`。状态迁移的功能范围为单次训练运行内的优化器状态管理。

### 2. 分组学习率与位置衰减

`gaussian.lr_mode=uniform` 保留原统一学习率；`grouped` 使用以下倍率，均乘顶层 `learning_rate`：

| 参数 | 倍率 | 顶层学习率 0.001 时 |
| --- | ---: | ---: |
| 三维位置 means | 0.16 | 0.00016，随后指数衰减 |
| 对数尺度 log_scales | 5 | 0.005 |
| 四元数 quaternions | 1 | 0.001 |
| SH 系数 sh_coeffs | 2.5 | 0.0025 |
| 不透明度 opacity_logits | 25 | 0.025 |

位置最终学习率为初始值的 `position_lr_final_ratio` 倍，默认 0.01。当前 SH DC 与高阶系数共用一个学习率组；原论文为两者设置不同学习率。分组倍率为本次实验预设。

### 3. 可见性累计的屏幕梯度密度控制

`density_strategy=legacy` 调用原有密度控制。`adaptive` 从实际渲染图的计算图中保留二维投影中心梯度：gsplat 返回 `means2d/radii`；reference 后端使用项目的二维投影结果。两种路径均将可见高斯索引映射回全体高斯，验证视角不参与累计。

梯度按图像宽高归一化后，在增密间隔内按可见次数求均值。高梯度、小尺度高斯克隆；高梯度、大尺度高斯用沿最大主轴的两个对称子高斯替换。增长候选按梯度稳定排序，受容量限制。低透明度、过大三维尺度或屏幕半径的高斯可被剪枝。

子高斯采用确定性对称偏移并缩小尺度，便于复现；原版使用随机采样分裂。此策略还包括增密窗口、周期性透明度重置，以及重置后的短暂增密暂停。本次消融整体评价这组密度策略，收益归因范围为上述规则组合。

相关参数：`densify_start`、`densify_stop`、`grow_grad2d`、`split_scale`、`prune_scale`、`prune_screen_radius`、`min_opacity`、`opacity_reset_every`。`densify_every=0` 仍关闭拓扑增密；自适应策略的透明度重置由自己的间隔独立控制，设为 0 可关闭。

### 4. L1＋SSIM 损失与统一评价

`gaussian.loss=mse` 保留原损失；`l1_ssim` 使用 `(1-w)*L1 + w*(1-SSIM)`，`ssim_weight` 默认 0.2。SSIM 使用有效区域的高斯窗口（11×11、sigma=1.5）、RGB 三通道平均、data_range=1。极小协议测试图像使用可容纳的最大奇数窗口。

所有方法均用相同、未经额外裁剪的实际浮点 RGB 计算验证 MSE/SSIM。PNG 展示沿用项目原有的显示裁剪与量化，因此从导出的 8-bit PNG 反算 PSNR 可能略有差异。MSE 与 L1＋SSIM 的训练 loss 分别按各自定义解释，验证指标使用统一口径。

最终 `metrics.psnr` 继续使用 `-10log10(各等尺寸验证图像的平均 MSE)`，保持历史口径。同时保存逐视角 PSNR、SSIM、真实验证渲染图、峰值 CUDA allocated/reserved 内存。中途预览 PSNR 对应首个验证视角，最终分数覆盖全部验证视角。

### 5. 界面、接口与兼容性

工作台新增四个策略选项和高级参数，导入/导出复用后端严格校验。旧配置缺失字段自动补默认；NeRF 沿用既有网络、采样和训练损失。CPU 数学参考后端与既有 gsplat CUDA 渲染保持可用。新增结果仍可使用原工作台实时查看。

较大地图的场景概览改为按相机批量计算逐点平均重投影误差，避免为每个点提前创建完整观测字典；完整轨迹仍在选点时按需读取。相机、点坐标、原始 ID、汇总指标和按需详情接口保持原定义，新增测试覆盖正常、空地图和零深度场景。离线实验期间工作台会阻止新的 GPU 训练/实时会话，实验进程退出后自动释放占用标记。

## 实验设计

`scripts/run_3dgs_ablation.py` 串行执行，每项训练独立启动 Python 进程，释放上次训练的 GPU 内存。每项保存完整配置、输入照片/模型/清单 SHA256、训练代码 SHA256、源代码副本、软件/硬件信息及原始指标。

当前具备三组输入：TempleRing 47 图、Temple 312 图、Dino 已注册 321 图，覆盖两种物体身份；TempleRing 与 Temple 为同一物体的两组照片。SfM 位姿、稀疏点与初始化 RGB 来自全图地图，可能包含留出照片的信息。训练损失使用训练视角，test 留出外观监督，训练与评价共享全图估计的几何。评测范围为固定地图、逐场景拟合条件下的留出视角合成；所有变体共享同一地图，用于比较训练策略的相对收益。

| 变体 | Adam 状态 | 学习率 | 密度控制 | 图像损失 |
| --- | --- | --- | --- | --- |
| baseline | 整体重置 | 统一 | 原有 | MSE |
| adam | 保留/迁移 | 统一 | 原有 | MSE |
| lr | 保留/迁移 | 分组＋位置衰减 | 原有 | MSE |
| density | 保留/迁移 | 统一 | 自适应 | MSE |
| loss | 保留/迁移 | 统一 | 原有 | L1＋SSIM |
| combined | 保留/迁移 | 分组＋位置衰减 | 自适应 | L1＋SSIM |

`adam-baseline` 隔离优化状态修复；`lr/density/loss-adam` 分别比较各策略；`combined` 测量组合策略及其交互效应，组合收益由对应的独立对照报告。

筛选阶段预设为 3,000 步、160×120、种子 0/1、相同 100,000 高斯预算、相同初始点和输入顺序。每组内验证划分固定：TempleRing 每 4 个已注册视角留一张，另外两组每 20 个留一张。留出视角排序后交替分成 dev/test；梯度训练使用训练集，仅用 dev 比较与选择完整预算确认配置；阈值调节的数据范围限于训练集/dev，test 用于留出评价。每个场景分别拟合模型。

低预算实验用于消融筛选。最终确认以相同分辨率、相同预算重新比较控制组和候选，PSNR 增益由各分辨率条件内的配对结果计算。

自适应组筛选时的增密窗口为 `[500, 2000)`，原有策略仍按每 100 步执行至训练结束。该组同时改变梯度指标、窗口、筛选和分裂规则，收益归因范围为这些规则的组合。默认透明度重置间隔为 3,000 步，筛选阶段的触发次数为 0；10,000 步原图确认将窗口延长到 `[500, 6666)`，因此会在 3,000/6,000 步重置透明度。

额外安排固定拓扑的损失对照：三组输入、种子 0/1、3,000 步，MSE 与 L1＋SSIM 均关闭增密并保留 Adam，因此高斯数完全相同。原因是两类损失的梯度量级不同，原有密度阈值固定时，损失改变也会改变高斯增长。主消融反映训练策略的总体收益；固定拓扑对照进一步区分损失本身与容量增长的贡献。

完整执行预设共 50 项训练：36 项筛选、12 项固定拓扑控制，以及 Temple312 原图 640×480 的两项 10,000 步确认（旧基线/仅由 dev 选出的候选，种子均为 0）。

### 结果解读与适用范围

- 本轮最稳定的单项策略组是分组学习率＋位置衰减：三个输入组测试 PSNR 较旧基线提高约 2.2–4.5 dB，高斯数量及训练时间变化相对较小。该对照评价学习率倍率与位置衰减的组合。
- 固定高斯数后，L1＋SSIM 测试 PSNR 提高约 0.47–0.73 dB，SSIM 也提高。这是固定容量下的损失函数收益估计；完整组合还包含学习率与密度策略变化，整体收益按组合实验报告。
- 原图组合的画质收益伴随约 2.09 倍训练时间、4.08 倍实际高斯数和更高显存。训练迭代数和容量上限相同，实际计算成本随策略变化。
- Adam 状态迁移修复了拓扑变化时的优化历史丢失；本轮 Adam 单项组在三个输入组的测试 PSNR 均低于旧基线，具体结果见上表。
- 分组学习率、密度策略、损失是预设的策略组；组合收益包含策略间交互，由组合对照单独报告。
- 所有变体共享容量上限，实际高斯数随训练策略变化。L1＋SSIM 会改变梯度和增密，高斯数、时间、显存应一并比较；固定拓扑实验用于辅助归因。
- 本轮覆盖两种物体、三个输入组、两个筛选种子，最终原图确认使用一个种子。
- 所有实验重用固定 SfM 位姿，相机参数在训练期间保持固定。

原始证据：`aggregate.json/csv`、`fixed-topology/aggregate.json/csv`、`full-resolution/aggregate.json/csv`、每项 `ablation_result.json` 和逐视角 `summary.json`。大型权重保存在本机 `runs/`，通过 Git 忽略规则在本地管理。原图确认的两份结果已复制到 `outputs/ablation_*`，刷新工作台历史后可查看；源实验保留原路径。

### 在工作台中使用

查看历史模型需本机已有原实验结果；刷新历史后可查看已完成模型、对照照片和自由视角渲染，公开仓库提供复现配置与紧凑指标。重新训练时，先准备 Temple312 照片并生成 SfM 源模型，再在工作台选择自己的 SfM 结果，进入 NeRF / 3DGS，导入 [原图确认配置](../configs/3dgs_temple312_optimized.json)。该历史实验的固定地图含 312 台相机、19,648 点；更换地图后属于新的对照条件。

### 短训练的收尾保护
