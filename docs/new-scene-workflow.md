# 新场景：照片 → 3DGS → 文本检索

这条流程使用目标场景自己的照片和 RGB 检查点生成无标注语义索引。当前新场景输出是**尚未验证的可见高斯候选区域**。

## 前提

- 照片、已知内参、有效位姿和稀疏点云。从无位姿照片开始时，先运行 SfM；当前 3DGS 使用稀疏点云初始化。
- 已安装兼容的 PyTorch、gsplat，以及 SAM/OpenCLIP 依赖和本地权重，见 [使用指南](usage.md) 和 [语义流程](semantics.md)。
- 一个可用 CUDA 设备。在页头显式选择主机上存在的物理卡；默认编号为 7，使用前需确认可用。索引、检索、训练与实时会话按项目资源互斥运行。
- 新场景语义任务目前通过项目的 `.venv/bin/python` 启动，按 **Linux 服务端**部署；Windows 可通过 SSH 隧道和浏览器使用。本机 Windows 语义任务尚未验证。

## 工作台操作

1. **导入照片。** 启动 `python -m minicolmap ui`，在当前服务地址打开 **重建与训练**（`#workspace`），选择或上传数据并检查 K 与尺寸。地址默认是 `http://127.0.0.1:8765`；SSH 转发时使用自己的本地转发端口。
2. **估计相机与点云。** 点击 **开始 SfM 重建**，等待完成并检查注册照片、轨迹和重投影。修正注册不足、内参错误或地图断裂等问题后，再用于训练。已有带稀疏点的合法模型时可导入并关联原图。
3. **训练 RGB。** 进入 **NeRF / 3DGS**，选 3DGS，关联模型和照片，选择 CUDA/gsplat，设置预算后训练。完成 RGB 和多视角几何的质量检查与修正后，再建立语义索引；语义训练使用固定的 RGB 与几何。
4. **建立独立语义场景。** 在完成的 3DGS 历史项点击 **用于语义检索**。服务校验原图、来源模型和 RGB 检查点，创建或复用对应的独立场景，各场景分别保存。
5. **生成索引。** 点击 **生成语义索引**。后台依次运行准备、SAM/CLIP 提取、区域组织、PCA32 编码与 3,000 步冻结 RGB 的语言场蒸馏，界面显示真实阶段及错误。检索时先停止实时浏览并等待计算资源释放。
6. **查询与检查。** 输入英文描述，例如 `red mug`。系统从训练照片中选择最相关的观察位置，生成三维候选；使用高亮、单独查看、恢复场景，旋转到不同角度核对。候选集中度不足时返回“未找到”，表示本次查询未得到符合筛选条件的候选；场景内的实际物体需结合其他观察核对。
7. **导出。** 若得到候选，可导出 ZIP：包含选中索引、检查点中的高斯张量和带来源/归一化信息的元数据。导出的几何表示为选定观察相机下的可见高斯表面选区，场景尺度尚未标定。

## 索引与结果

| 项目 | 当前行为 |
| --- | --- |
| 场景配置 | 自动生成 schema v2 配置；语义标注与 Dev 列表为空，使用目标场景自身数据 |
| 默认压缩 | PCA32，在语义训练视图的区域特征上拟合；官方 LangSplat 使用 3 维自编码器 |
| 训练照片 | 来源模型中已注册照片，排除 RGB 检查点的验证 ID；至少需要 2 张训练照片 |
| 冻结内容 | RGB、几何、不透明度和高斯顺序不变；只学习每高斯语言特征 |
| 结果 | 选定观察相机下的可见语义候选，附来源与状态；未做新场景语义准确率、校准置信度或跨视角发布验证 |

配置放在项目 `configs/`，派生数据放在 `data/semantic_scenes/scene-*/`。RGB 检查点、来源模型、照片清单、模型清单、压缩器和语言场均有身份关联；改动来源后会拒绝复用旧索引或选区。配置或算法发生变化时使用新的 workspace，并生成完整匹配的产物。

候选同时受文本响应、相机可见性、深度门限、空间连通性与大小限制约束，用于过滤明显无效区域。**候选的物体身份、语义正确性、覆盖范围与跨视角一致性需分别核验**。遮挡、低纹理、相似物体、CLIP 混淆、压缩误差和跨视角不一致都可能导致漏选或误选；检查需覆盖锚点及其他观察角度。

Waldo Kitchen 的已筛选示例使用独立的 raw3/多视角验证路径。方法差异见 [语义指南](semantics.md)，实验条件与逐项结果见 [实验摘要](../reports/README.md)。

## 资源占用与排错

- 索引/查询报 GPU 占用时，结束自己启动的实时浏览或等待已有任务完成，保留其他使用者的任务与资源预留。
- 权重缺失或校验失败时，按 [语义模型准备](semantics.md#模型与环境) 检查，完成真实权重校验后再重试。
- 缺原图、稀疏点或足够训练视图时，先补齐 RGB 任务来源并完成照片注册，再重试。
- 清理入口在 **重建与训练 → 历史 → 本地任务记录**。确认范围后删除 RGB 任务也会清理其独立语义场景；活动任务或被引用的结果受保护，详见 [任务与清理](usage.md#任务gpu-与清理)。
